# Get-SnowplowConfiguration

## SYNOPSIS
Returns module-level settings.

## SYNTAX

```
Get-SnowplowConfiguration [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Returns settings such as the default backend.

## EXAMPLES

### EXAMPLE 1
```
Get-SnowplowConfiguration
```

Shows the current settings.
